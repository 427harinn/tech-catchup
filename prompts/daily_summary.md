# Daily Summary Prompt

Phase 3でCodex要約連携を実装するときに利用する予定のプロンプト置き場です。

## Guardrails

- 要約は元記事の代替になりすぎない範囲に留める
- 元記事URLを必ず残す
- 記事本文全文を保存用データとして扱わない
- 保存対象はタイトル、URL、概要、公開日、要約、次アクションなどの必要最小限にする
- 要約対象の取得頻度は抑え、大量アクセスを避ける
- robots.txt や利用規約に反する本文取得は行わない

## Intended Focus

- 個人開発に使えるか
- 業務システムに応用できるか
- アバター、Unity、Web、3D、AI活用に関係するか
- 今すぐ試す価値があるか
- Notionに残す価値があるか
