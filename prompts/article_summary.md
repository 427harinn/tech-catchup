# Article Summary Prompt

以下の記事情報をもとに、個人用の技術キャッチアップ向けに要約してください。

制約:

- 元記事の代替になりすぎないこと
- 記事本文全文の再掲はしないこと
- タイトル、URL、概要、公開日を中心に扱うこと
- 自分向けの関係性は1〜2文で短く書くこと

観点:

- 個人開発に使えそうか
- 業務システムに応用できそうか
- アバター、Unity、Web、3D、AI活用に関係するか
- 今すぐ試す価値があるか
- 後で読むだけでよいか
- Notionに保存する価値があるか

出力形式:

```json
{
  "summary_short": "3行程度の要約",
  "tech_points": "技術的に重要なポイント",
  "relevance": "関係ある理由を1〜2文で短く",
  "tags": ["AI", "Web", "Cloudflare"],
  "priority": 4
}
```

対象記事:

```json
{{ARTICLE_JSON}}
```
