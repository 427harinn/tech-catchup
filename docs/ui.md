# UI 方針

## 基本方針

- 通常一覧は `status = summarized` かつ `archived_at IS NULL` の記事を中心に表示する
- 未要約記事や要約失敗記事は、通常のユーザー向け一覧には出さない
- 手動登録記事は `source = manual` として、見た目でも区別する

## レイアウト

- スマホ優先で 1 カラム表示
- スマホでは 1 記事を縦にしっかり読めるカードサイズを優先する
- PC では 2〜3 カラムで一覧性を残す

## 操作

- 上部に `取得＆要約` ボタンとジョブ状態をまとめる
- 手動 URL 登録は上部フォームから `summarize_link` ジョブを作成する
- `興味ある` `興味なし` `試したい` は一覧全体を再読込せず、該当カードだけを部分更新する
- `試したい` は Notion 保存状態がカード内で分かるようにする

## フィルタ

- まずは `すべて / 興味あり / 試したい / 手動登録`
- 検索欄、優先度、情報源フィルタを先に配置する
- 将来的にタグ、詳細検索、並び替えを追加しやすい構造にする
